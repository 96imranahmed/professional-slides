# Argument With Chart

## Use when

Use this archetype when the audience needs a verbal argument, mechanism, scenario, or qualification before quantitative evidence can be interpreted correctly, and one chart or a coherent quantitative evidence set provides corroborating proof.

Use [`chart-led insight`](chart-led-insight.md) when the quantitative pattern is the primary page logic and can be understood with concise annotation. Use [`text-led implication`](text-led-implication.md) when no quantitative exhibit is required.

## Narrative contract

The argument region states the primary proposition and explains the reasoning; the evidence field tests, bounds, or substantiates one quantitative part of that proposition. The evidence may include a chart, coordinated charts, or a chart combined with another quantitative exhibit such as a map or table, but it must strengthen the argument without introducing a competing conclusion.

## Content contract

- one page-level action title or a theme-approved split-title treatment in which the argument heading carries the primary claim;
- one concise argument block containing the mechanism, condition, example, or qualification the chart cannot express;
- one supporting quantitative evidence field containing a single chart or two to three coordinated exhibits selected through the [`chart router`](../charts/index.md) and [evidence-composition guide](evidence-compositions.md);
- one subordinate evidence heading per primary section that states the measured subclaim, scope, or evidence question;
- one source treatment covering both the verbal and quantitative evidence.

## Layout

Use a stable argument-plus-evidence split, normally `4 + 8` or `5 + 7` columns. Place the argument on the reading-order side and the evidence in the wider region. Separate the regions through the slide family's defined whitespace or rule; never insert an improvised divider on one page.

Align the argument heading with the first evidence heading, and align the argument body with the visible plot area, map crop, or table body beside it when practical. Reserve enough width for labels before fixing the split, and keep all legends, totals, annotations, and callouts inside the evidence field.

Use a [progressive evidence path](evidence-compositions.md#progressive-evidence-path) when the page moves from reasoning to a benchmark chart and then to a geographic, segment, or customer deep dive. Use a [parallel evidence field](evidence-compositions.md#parallel-evidence-field) only when the argument applies equally to peer exhibits. Do not add a separate synthesis rail when the argument region already performs the interpretive role.

## Visual rules

- Keep the argument region typographic and restrained so the quantitative field remains the dominant evidence object.
- Use one established heading hierarchy across both regions; the chart heading is subordinate to the page-level claim even when it is visually prominent.
- Apply each selected chart family's encoding and annotation rules without copying colours or label treatments from the argument region.
- Use an evidence-side metric or total only when it answers a distinct evidence question and remains visually attached to its exhibit.
- Preserve the selected split, separator treatment, content tops, and source baseline across every slide in this family.

## Failure modes

- a chart that merely illustrates an example without testing the argument;
- several exhibits that answer unrelated questions or can be removed without weakening the proposition;
- two independent action titles that make the page read as unrelated half-slides;
- narrative copy that explains every visible bar or point instead of supplying missing reasoning;
- a 50/50 split that leaves the chart too narrow for honest labels or scales;
- a decorative vertical line that does not belong to the active slide family;
- duplicated sources, legends, or takeaways on both sides.

## Acceptance test

Cover the evidence field: the argument should remain coherent but visibly under-supported. Cover the argument: the exhibits should remain readable but incomplete as a decision message. Reveal both: the complete evidence path should substantiate the argument as one page-level claim.
