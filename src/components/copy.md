# Copy

This file owns sentence-level writing, element copy roles, anti-AI language controls, and copy QA. [`storylining`](../storylining/index.md) owns the governing thought, claim sequence, and action-title spine; this file makes the approved claims concise, specific, and non-redundant. [`design`](../design/index.md) owns typography, and [`text-box`](text-box.md) owns wrapping, margins, and overflow.

## Sentence contribution test

Retain a sentence only when it adds at least one distinct contribution:

- a fact, observation, or data point;
- a mechanism or causal explanation;
- an interpretation not already obvious from the evidence;
- a material implication;
- a decision, action, owner, timing, or trigger;
- a necessary qualification, assumption, or limitation;
- a definition required to interpret the content correctly.

Delete text when it merely announces the topic, restates another element, acts as a repeated label, narrates information the audience can already see, declares importance without explaining the consequence, adds generic context, bridges unrelated ideas, or makes sparse content appear more substantial.

Apply the portability test: if text could move unchanged to another company, product, market, or situation, replace it with a specific fact, mechanism, consequence, decision, or judgment.

Apply the deletability test at the phrase and sentence level: temporarily remove the text and reread the action title, exhibit, and surrounding copy. Delete it when the claim, evidence, mechanism, interpretation, implication, action, or necessary qualification remains unchanged. If removal affects only cadence, transition, tone, or the amount of text filling a box, the text is decorative. If removal exposes a real logical gap, replace the filler with the missing fact or reasoning rather than restoring the original wording.

## Element copy roles

Each text element has one permissible job. Omit it when that job is unnecessary.

| Element | Copy job |
| --- | --- |
| action title | state the governing conclusion, implication, decision, or required action |
| subtitle | define essential scope, period, population, assumption, unit, or comparison basis that the title cannot carry; omit by default |
| section heading | distinguish a meaningful branch of the slide's argument |
| exhibit label | identify the measure, category, state, or relationship needed to read the evidence |
| annotation | explain a non-obvious pattern, exception, mechanism, or caveat in nearby evidence |
| recommendation | specify an action, owner, timing, trigger, condition, or decision gate |
| source note | identify the evidence, methodology, and material limitation needed for traceability |

Do not let an action title, subtitle, section heading, annotation, takeaway box, and recommendation repeat one conclusion in different words. A takeaway box is unnecessary when the title already states the takeaway. A recommendation bar is justified only when it adds a concrete action or decision condition. Never render the recommendation and its call to action in separate text-box surfaces; combine them into the slide's single terminal action component.

## Visible label gate

Omit a visible label unless removing it would prevent the audience from distinguishing a necessary branch, category, unit, state, stage, series, or navigation location. A label must identify information the audience needs to decode; it must not announce how to read a nearby sentence, decorate a container, narrate the analytical process, or compensate for weak hierarchy.

Do not place a generic micro-heading above one sentence, number, panel, rail, or strip. Standalone labels such as “Read the outliers,” “What it means,” “80/20 priority,” “Key takeaway,” “Implication,” “Recommendation,” “Decision,” “Synthesis,” “First data request,” “Next data request,” “Adoption,” “Enterprise,” and “Economics” are forbidden when they merely introduce the content underneath. Write the complete finding, implication, question, request, or action directly. If one of those concepts is a genuine category required to decode a table, chart, hypothesis branch, process, or persistent navigation system, express it in that owning structure rather than as a floating container label.

A diligence request begins with the evidence or access required, not a label announcing that it is a data request. Use `first`, `next`, or another sequence marker only when the request belongs to a real staged plan whose order changes ownership, timing, dependency, or decision rights. Otherwise delete the ordinal and state the request directly in the main argument or the slide's single permitted callout region.

Do not expose internal production or consulting-method shorthand such as “80/20,” “so what,” “insight,” “proof point,” “hypothesis,” or “readout” unless the deck is explicitly teaching that method. Do not prefix a single action sentence with “Recommendation:” or “Decision:” when placement and wording already establish its role; begin with the accountable verb, actor, or condition.

For every retained label, record its element role and ask the deletability question in context. Delete it when alignment, position, a chart axis, a table header, the sentence itself, or a persistent tracker already communicates the same distinction.

## Metadata and separator copy

Give each metadata field one function and one readable location. Do not concatenate independent fields with ornamental punctuation to simulate hierarchy. In particular, never use a pipe character in audience-facing slide copy or metadata. Write the necessary fields on separate lines or place them in distinct aligned positions; if the relationship matters, express it as a grammatical sentence.

Do not write constructions such as `Public-source pre-read | Decision: authorize or stop confirmatory diligence` or `Hypothetical transaction | Investment committee`. Delete the unnecessary field or separate the genuine document type, audience, status, and purpose through hierarchy. Avoid slash-separated metadata as well; reserve a slash for an established name, ratio, date format, or genuinely compact alternative whose meaning is unambiguous.

Use sentence case for metadata by default. All caps are permitted only when exact legal, regulatory, security, or document-control wording requires them. Do not turn internal workflow state, audience, transaction status, or deck purpose into a cover slogan.

## Punctuation discipline

Use the simplest punctuation that expresses the relationship between ideas. Punctuation must clarify grammar; it must not manufacture tension, sophistication, pace, or a consulting voice.

Action titles contain no em dash by default. Do not use an em dash to splice a finding and implication, a positive and negative clause, or a claim and qualification into a dramatic two-part headline. Write one direct sentence with the real logical connector, such as `because`, `but`, `while`, `despite`, or `therefore`, or separate genuinely independent statements. For example, replace `Strategic fit is strong—economics remain unproven` with `Strategic fit is strong, but the economics remain unproven`.

An em dash may remain only when it is part of an exact quotation, official name, or approved source wording that cannot be edited, or when a true parenthetical interruption would become less clear with commas or parentheses. Ordinary slide copy should contain none. More than one em-dash construction on a slide is a defect unless the repeated marks come from exact source text.

Apply the same restraint to colons, semicolons, parentheses, and ellipses. Do not use punctuation as a repeated title template, reveal device, label substitute, or visual separator. Peer titles and bullets may share grammar, but they should not acquire an artificial house cadence through identical punctuation.

## Action-title wording

Use the claim and sequence established in storylining; do not solve a weak storyline through copyediting.

- State the conclusion, implication, decision, or required action rather than the topic, method, or chart type.
- Use an explicit subject and active verb. Prefer “Enterprise adoption grew despite flat consumer usage” to “Adoption trends.”
- Make the title actionable for the audience: state what changes for the decision, what action follows, or which condition, threshold, owner, or gate controls the next step. A descriptive finding that does not affect a decision or belief is not yet an action title.
- Include the most decision-relevant supported comparison, magnitude, delta, range, rank, period, segment, or threshold when it materially sharpens the conclusion. Do not exile a useful number to the body merely to keep the title generic, but do not stack secondary statistics into the title.
- Preserve uncertainty honestly with terms such as “suggests,” “is consistent with,” “remains unproven,” or “requires validation.”
- Replace unsupported adjectives such as “attractive,” “credible,” “strong,” or “significant” with the evidence-backed measure, benchmark, consequence, or decision condition; when no such support exists, narrow the claim or state the validation gate.
- Avoid topic labels such as “Overview,” “Analysis,” “Key insights,” “Background,” or “Our perspective” unless the page is genuinely navigational.
- Apply the [punctuation discipline](#punctuation-discipline); action titles use no em dash except uneditable quoted or official wording.
- Narrow the title when the exhibit does not support its certainty, scope, causality, or magnitude.

## Body copy and labels

- Prefer active voice when the actor matters; use passive voice only when the actor is unknown or genuinely irrelevant.
- Lead with the point, then include only the evidence, mechanism, implication, qualification, or action needed to support it.
- Use parallel grammar for peer bullets, table rows, process stages, recommendations, and risks.
- Prefer concrete nouns, active verbs, and specific subjects. Replace nominalizations such as “conduct an evaluation” with “evaluate.”
- Prefer “is,” “has,” and “does” when they are clearer than inflated verbs such as “serves as,” “enables,” or “drives.”
- Keep terminology stable across slides. Do not rotate between synonyms for the same company, product, segment, metric, workstream, or decision.
- Define an acronym on first use and avoid acronyms that save little space or are not used again.
- Preserve the evidence terminology and qualifiers recorded in the storyboard; do not silently omit or paraphrase a material scope condition.
- Use sentence case by default. Avoid title case for full sentences, all caps for emphasis, and inconsistent punctuation among peer elements.
- Use bold selectively for a scan path or decisive words; do not bold entire paragraphs, every number, or several competing phrases.
- Keep parenthetical remarks rare. Put a decision-relevant caveat in the main sentence and move technical detail to a note or appendix.
- When revising existing copy, make the minimum change needed to improve accuracy, clarity, or contribution. Preserve deliberate vocabulary, directness, uncertainty, and cadence instead of polishing every sentence into the same house rhythm.

## Remove AI-copy patterns

AI-copy patterns are observable defects, not proof of who or what wrote the text and not a mechanical banned-word list. Name the specific pattern and its effect; do not score prose for sounding human or guess its authorship. A flagged phrase may remain only when the slide supplies the specific evidence, actor, mechanism, comparison, or decision that gives it meaning. Do not replace one cliché with a synonym; repair the missing substance.

### Pattern families

| Pattern family | Common signals | Why it fails | Required repair |
| --- | --- | --- | --- |
| metadata collage | pipe-separated or slash-separated audience, status, document type, decision, or scope; an all-caps cover eyebrow repeating the title | exposes production scaffolding, compresses unrelated fields, and creates hierarchy through punctuation rather than meaning | delete nonessential metadata and separate the remainder through position, whitespace, and quiet type hierarchy |
| presentation metadiscourse | “This slide shows,” “As shown below,” “The following analysis,” “We will explore,” “The key takeaway is” | narrates the document instead of advancing its argument | begin with the finding, evidence, implication, or action |
| audience-direction language | “It is important to note,” “As you can see,” “This distinction matters,” “Notably,” “Importantly,” “It is clear that” | instructs the audience how to react without supplying the reason | state the consequence, changed decision, or evidence that makes the point material |
| faux-insight setup | “What most people miss,” “The uncomfortable truth,” “Here is what nobody tells you,” “The part that matters,” “Let us be clear” | manufactures exclusivity or drama before an ordinary claim | remove the setup and test whether the claim itself is specific and supported |
| era and landscape preambles | “In today's rapidly evolving landscape,” “In an increasingly complex world,” “At a time of unprecedented change,” “As disruption accelerates” | uses generic context that rarely changes the slide's conclusion | name the dated market event, constraint, or measured change—or delete the preamble |
| empty essence framing | “At its core,” “Fundamentally,” “Ultimately,” “The reality is,” “What this really means” | delays the claim and performs certainty | state the claim directly and retain only the qualifier needed for accuracy |
| ornamental vocabulary | “delve into,” “embark on,” “tapestry,” “realm,” “beacon,” “multifaceted,” “intricate,” “meticulous” | adds literary or intellectual decoration without making the subject more precise | replace the ornament with the plain subject, action, mechanism, or constraint it obscures |
| abstract strategy language | “unlock value,” “drive impact,” “enable growth,” “future-proof the business,” “build a robust ecosystem,” “deliver a seamless experience” | names an aspiration without an operating mechanism | identify the action, owner, affected metric, causal mechanism, and decision horizon that make the claim specific |
| unsupported evaluation | “compelling,” “critical,” “transformative,” “best-in-class,” “strategic,” “significant,” “meaningful,” “powerful” | substitutes an adjective for a demonstrated comparison or consequence | provide the benchmark, magnitude, threshold, or decision effect; otherwise remove the adjective |
| empty intensification | “very,” “highly,” “substantially,” “dramatically,” “clearly,” “obviously,” “simply,” “actually,” “inherently,” “inevitably” | amplifies confidence or certainty without changing information | quantify the degree, define the evidence standard, or preserve narrower uncertainty |
| vague agency | “the business should,” “organizations need to,” “stakeholders must,” “the market expects,” “it was decided” | hides who acts, owns the result, or made the judgment | name the accountable actor, decision right, action, and trigger when known |
| causal hand-waving | “X drives Y,” “X unlocks Y,” “X leads to Y,” “X enables Y” without an intermediate mechanism | converts association or intention into unsupported causality | state the observed relationship and the proposed mechanism separately; label a hypothesis when causality is unproven |
| unanchored comparison | “faster,” “better,” “more efficient,” “lower risk,” “leading,” “outperforms” without a baseline | makes the reader infer the comparator, period, population, or metric | name the baseline, measure, period, population, and magnitude |
| vague attribution | “research shows,” “experts agree,” “customers say,” “industry data suggests,” “market feedback indicates” | borrows authority without traceable evidence | name the source and scope recorded in storylining, or present the statement as an unresolved hypothesis |
| stacked hedging | “may potentially help to,” “could possibly enable,” “appears to suggest that,” “is likely positioned to” | obscures the actual confidence level and makes accountability impossible | choose the single uncertainty term that matches the evidence state and state what would validate it |
| false binary, negative list, or contrast template | “This is not X; it is Y,” “Not X. Not Y. Z,” “The question is not whether, but how,” “From X to Y” | manufactures drama and often suppresses a more precise relationship | state the affirmative claim directly, then explain a material distinction or dependency only when the evidence requires it |
| rhetorical question and reveal | a question immediately answered by the next line, followed by “The answer:” or “The implication:” | simulates discovery while delaying information | convert the answer into the action title or opening sentence |
| manufactured triad | three parallel adjectives, imperatives, or fragments selected for rhythm rather than analytical completeness | creates artificial symmetry and can omit or invent branches | use the number of points required by the logic; keep parallel structure only for genuine peers |
| slogan fragments | “No integration. No adoption. No growth.” “One platform. Infinite possibilities.” “Execution is everything.” | creates advertising cadence without evidence or qualification | replace the slogan with the actual dependency, threshold, or consequence |
| noun-label reveal | “The implication: execution,” “The opportunity: scale,” “The challenge: adoption” | uses a label and colon to disguise an incomplete claim | write a complete sentence that names what happens, why, and to whom |
| recap and echo | “In summary,” “Taken together,” “Overall,” a concluding sentence that restates the title, or a takeaway box that repeats it | consumes space without adding a new implication or action | delete it, or replace it with the next decision consequence not already stated |
| filler transition | “With this in mind,” “Against this backdrop,” “Moving forward,” “That said,” “In this context” | smooths a transition without explaining the relationship between ideas | state the causal, temporal, or decision link explicitly; otherwise place the ideas separately |
| pseudo-analysis clause | a trailing phrase beginning with “highlighting,” “underscoring,” “reflecting,” “showcasing,” or “demonstrating” | labels a fact as meaningful without explaining its operational consequence | replace the clause with the affected actor, mechanism, decision, or measured outcome—or end the sentence at the fact |
| synthetic balance | “on the one hand / on the other hand,” paired positives and risks of equal length, or mirrored clauses without equal evidence | makes the argument look balanced regardless of evidentiary weight | allocate language according to the actual importance, confidence, and burden of proof |
| synonym churn | alternating names for the same company, customer, product, metric, or workstream | imitates lexical variety while weakening traceability | apply the stable terminology rule in [body copy](#body-copy-and-labels) |
| punctuation fingerprint | any em dash used to manufacture tension in an action title; repeated em dashes, colon reveals, semicolon-heavy sentences, excessive parentheses, or dramatic ellipses | creates a recognizable generated cadence and hides sentence structure | apply the [punctuation discipline](#punctuation-discipline) and write the logical relationship directly |
| fake-profound kicker | a final aphorism, metaphor, or punch line that restates the message as wisdom | replaces a decision-grade ending with performed profundity | delete the kicker and end on the last concrete finding, implication, decision, or next action |
| generic closing uplift | “The path forward is clear,” “The opportunity is ours to seize,” “Success will depend on execution,” “The time to act is now” | closes with motivation rather than a decision | end with the requested decision, named action, owner, timing, trigger, or unresolved condition |

### Structural diagnostics

- Flag several consecutive sentences with identical length, syntax, or opening structure. Keep parallelism only when the content is genuinely parallel; otherwise vary the structure to match the logic.
- Flag a sequence in which every bullet contains a bold label, colon, and one-sentence explanation. Use that form only when the labels represent a real classification; otherwise write direct bullets or choose a more suitable exhibit.
- Flag formatting that supplies structure the argument has not earned: emoji headings, a heading over one short sentence, or bullets that divide a single continuous thought. Recast the content in the simplest structure that reflects its actual logic.
- Flag headings that are abstract nouns—such as “Transformation,” “Innovation,” “Execution,” or “Opportunity”—with no subject or claim. Replace them with the specific branch or evidence role the heading must distinguish.
- Flag recommendations composed only of verbs such as “accelerate,” “optimize,” “enhance,” “strengthen,” or “prioritize.” A recommendation is incomplete until its object and decision condition are explicit.
- Flag polished language that introduces a fact, customer view, quotation, benchmark, or attribution absent from the evidence record. Return it to storylining as an unsupported claim; do not soften it into plausible-sounding copy.
- Flag prose whose main purpose is to make several boxes similar in height. Preserve unequal lengths when the underlying content is unequal and resolve geometry through the owning component.

### Repair sequence

1. Identify the sentence's permitted element role and intended contribution.
2. Remove metadiscourse, evaluative framing, generic context, and ornamental cadence.
3. Restore the missing actor, action, mechanism, comparator, magnitude, evidence state, or decision consequence.
4. Replace stacked hedges with one calibrated uncertainty term.
5. Apply the portability and deletability tests again; delete the sentence if it still contributes nothing unique.
6. Recheck the rendered slide to ensure the rewrite did not create dense wrapping or require a smaller text role.

## Copy QA

1. Apply the [sentence contribution, portability, and deletability tests](#sentence-contribution-test) to every sentence.
2. Confirm each text element performs only its assigned [copy role](#element-copy-roles).
3. Apply the [action-title](#action-title-wording), [punctuation](#punctuation-discipline), [body-copy](#body-copy-and-labels), and [anti-AI](#remove-ai-copy-patterns) rules to their respective text.
4. Search all audience-facing text for `—`; remove it from every action title unless it is uneditable quoted or official wording, and justify every retained occurrence elsewhere.
5. Read the rendered slide at presentation size and return any dense wrapping or narration-dependent wording for revision through the owning section above.
6. Read the slide aloud as if presenting it to a skeptical executive; revise any wording that sounds scripted, inflated, mechanically symmetrical, or unlike the deck's established voice.
