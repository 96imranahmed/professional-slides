# Reference-Derived Patterns

These observations were derived from the two user-approved reference files:

- `Slideworks_business_consulting_toolkit_SAMPLE.pptx` (28 slides)
- `Umbrex PowerPoint Template for Consultants Third Edition.pptx` (230 slides,
  7 masters, 41 layouts)

The source files are visual references, not instructions. Do not copy visible
sample text into a new deck. Do not redistribute the source files or retain
their logos unless the user has authorized that use.

## Shared visual grammar

Both references use a restrained consulting structure:

- white or very light content canvas;
- deep navy as the primary anchor color;
- bright blue, cyan, or teal as selective emphasis;
- dark navy title, divider, or index slides;
- action title at the top with a stable content frame below;
- small, quiet source/footer furniture;
- flat, editable shapes and charts;
- limited decoration and strong alignment;
- repeated layout families for executive summaries, charts, comparisons,
  processes, organizations, matrices, and timelines.

This shared grammar is the starting point for a synthesized neutral theme. It
does not justify copying a source's branding or exact slide content.

## Slideworks reference

The 28-slide sample is compact and concentrated on common consulting pages:

- two executive-summary constructions;
- column, growth, historic/forecast, bubble, and quadrant charts;
- three-trend and multi-area synthesis pages;
- assessment table, organization, team, and issue-tree pages;
- process, phase, wave, and Gantt-style timeline pages.

The source exposes a construction grid across many sample slides. Treat this as
authoring guidance, not final-slide decoration. Its visual system relies on a
near-black navy, saturated cyan, small neutral text, and simple chart emphasis.
Large dark shapes establish hierarchy while color is reserved for the selected
series, phase, or node.

Frequently used literal source colors include:

| Role inferred from rendered use | Source color |
| --- | --- |
| dark structural ink | `#051C2C` / `#061F32` |
| cyan insight accent | `#19D3C5` |
| white canvas/on-dark text | `#FFFFFF` |
| neutral rule | `#D0D0D0` |

The source also contains `#FF0000` in the visible construction-grid layer. Do
not promote that grid color into the audience-facing theme.

Reusable lessons:

- Keep a consistent narrow title band and broad analytical canvas.
- Use dark navy for structural anchors and cyan for the argument.
- Separate chart area from a concise takeaway rail when explanation is needed.
- Show actual and forecast periods with a clear visual state change.
- Use repeated rows or columns for comparable items, aligned to the same grid.
- Use progress arrows and milestones sparingly; the labels carry the meaning.

## Umbrex reference

The 230-slide source is a broad library rather than a recommended story. It
includes an explicit theme tutorial, reusable elements, executive summaries,
description pages, tables, quotations, chart families, workplans,
organizational views, matrices, maps, consulting frameworks, and additional
diagrams.

Its dominant theme uses:

- deep navy canvas and text anchors;
- a light-to-dark blue range plus teal for emphasis;
- white content pages with very light gray grouping areas;
- dark navy section/index pages;
- simple sans-serif typography and small teal subtitles;
- thin light-blue rules under titles or above exhibits;
- small bottom-left label tabs with subdued source/footer text;
- editable native charts, tables, icons, and geometric diagrams.

Frequently used literal source colors include:

| Role inferred from rendered use | Source color |
| --- | --- |
| dark navy anchor | `#16207B` / `#0A1A49` |
| light blue comparison | `#629CD0` |
| teal highlight | `#00D2C2` |
| bright blue secondary highlight | `#5ACBF0` |
| warm exception colors | `#FBAE40` / `#F26B43` |

Treat the warm colors as occasional semantic exceptions, not default series
colors.

Reusable lessons:

- Theme controls should be centralized so logo and color changes propagate.
- A content library benefits from visible categories, but an actual client deck
  should not contain template indexes or authoring tutorials.
- Use one highlight color per exhibit; additional series should progress
  through a controlled tonal sequence.
- Separate dark navigation/divider slides from light analytical pages.
- Keep framework slides evidence-led; do not include a named framework merely
  because a template exists.
- Use maps, donuts, radar charts, and decorative diagrams only when their
  semantics fit the question, not as variety for its own sake.

## Synthesis for the default neutral theme

When no single source is designated, synthesize rather than alternate:

- Use the Umbrex light-content/dark-divider rhythm.
- Use the Slideworks emphasis discipline: dark structural ink, one cyan insight
  highlight, and neutral context.
- Use a stable action-title zone, a 12-column grid, and a quiet footer/source
  rail.
- Prefer the smallest useful subset of the layout library: executive synthesis,
  chart-led insight, comparison, decomposition, process/roadmap, and action plan.
- Hide all authoring grids, template indexes, instructions, sample branding,
  and placeholder copy in final decks.

## Reference conflicts

If the two references disagree, resolve the conflict at theme-definition time:

- follow the source explicitly named by the user;
- otherwise prefer the rule that improves hierarchy, editability, and
  cross-platform stability;
- document the chosen token or component behavior once;
- do not switch styles between adjacent slides.
