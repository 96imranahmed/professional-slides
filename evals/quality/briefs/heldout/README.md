# Held-out briefs

These briefs are never used to tune the skill. Nobody reads a held-out run to
decide what to change in `skills/`; its only use is to say whether changes made
against the development set (`evals/cold-run/briefs/`) generalise.

Looking at a held-out run to find what to fix spends it: it becomes a
development brief. When that happens, move the brief to `evals/cold-run/briefs/`
with a note in its "Why this brief is in the suite" paragraph, and write a new
held-out brief in its place so the set stays at three.

The companies, programme and figures are fictional. Each brief carries all the
evidence the deck may use, so a run needs no research and two runs can be
compared deck against deck.
