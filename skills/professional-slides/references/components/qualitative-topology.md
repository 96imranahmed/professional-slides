# Qualitative selection and phase hierarchy

These are variants of the registered `funnel` and `timeline` owners. They use the shared native geometry and measured text adapters; they are not separate authoring paths.

`funnel` with `variant: 'qualitative'` requires `basis: 'qualitative-selection'`, two to five keyed `stages` (`id`, `label`, nonempty `details` array), `inputSources`, `inputDescription`, and a distinct `outcome` (`label`, nonempty `details`). The narrowing trapezoids communicate successive selection states schematically. Their widths do not encode counts, rates, shares or retention. Numeric stage values and denominators are rejected. Use the unchanged default quantitative funnel when measured values and a denominator exist. Source inputs sit above the narrowing states; the separate outcome below prevents a vetted option set from implying an authorized selection.

`timeline` with `variant: 'phase-hierarchy'` requires keyed `phases` with `label` and source-authored `duration` strings. `expandedPhaseId` selects the one phase whose keyed `children` are expanded below the two-or-more peer phases; `expansionLabel` describes that scope. Parent widths are equal and explicitly schematic: durations are text, never inferred from geometry. `phaseAnnotations` optionally binds one measured commitment per `phaseId`; overlapping annotation lanes reject. Each child carries the exact parent dependency, and the expansion connector names the parent and every child. Do not turn an estimated duration into an approved deadline.

Both variants measure shared heading and body roles at the current evidence density. Every text node records exact line layout for HTML/native parity. Neither reduces typography or discards content to fit. A failed capacity check requires a larger frame or an explicit source-preserving plan revision. The phase hierarchy has one expansion at a time; these variants do not infer quantitative funnels, elapsed-time scales, approval gates or child durations.
