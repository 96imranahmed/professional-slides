# Professional Slides directory listing draft

This copy is for the public plugin submission. It describes the current skill and runtime; it does not represent approval or publication.

## Subtitle

Plan, create and revise slides

## Description

Professional Slides turns a brief, analysis, or existing presentation into an editable PowerPoint deck built around a clear decision or message. Use it for board and steering committee papers, project updates, investor and pitch decks, commercial due diligence, executive summaries, and narrative pre-reads. Give it the audience, the decision or learning objective, the evidence it may use, the intended length, and any reference deck or visual identity.

For a new deck, the skill starts with the audience's question and the evidence needed to answer it. When the task calls for public research, it can gather source data and assets, record where facts came from, work through comparisons and counterarguments, and develop a hypothesis tree. It then writes a slide-by-slide dot-dash with exact proposed titles and each page's type so you can review the argument before the copy is written. Each claim gets an appropriate form: a chart, table, comparison, diagram, image, or concise prose. Registered starting points cover commercial due diligence, startup pitches, and project progress updates. Consulting, editorial, journal, and keynote design systems provide different page treatments rather than one fixed template.

You can also use the skill before requesting a file: ask it to clarify the governing answer, write a title spine, develop the slide-by-slide argument, identify missing evidence, or plan how an exhibit should prove a claim. It can distinguish the main case from counterevidence and mark where a conclusion depends on an assumption. A short deck follows the length in your brief; a longer pre-read can use denser evidence pages when the audience needs them.

For an existing deck, the skill inventories the source slides, tracks them by stable IDs, revises the claims and shared dependencies affected by your request, and builds the result as a new editable PPTX; your original file is not edited. It can restructure a deck, sharpen action titles, update evidence, or rework an individual slide of a deck it built while preserving unrelated pages. For a quick edit to an existing file, such as a typo or a single chart, a general PowerPoint tool is the better fit. It uses supplied decks as design or evidence references within the scope you set.

The runtime writes an editable PPTX. Eligible charts are native PowerPoint charts with embedded workbooks; tables, diagrams, text, labels, and many other elements remain editable objects. Subject colors, typography, page layouts, chart labels, annotations, notes, and sources are handled as part of the composition. If you provide a reference deck or brand colors, those can guide the visual system. A design intake can show rendered options for look, title treatment, surfaces, navigation, and density, and save preferences for later work.

The workflow distinguishes sourced facts from assumptions and scenarios, makes units and timeframes explicit, and identifies missing evidence instead of filling gaps with invented numbers. It checks whether a chart or table shows the relationship the title claims, whether comparisons use a consistent basis, and whether the executive summary reflects the analysis. Public data, logos, images, or map assets may be fetched when the brief calls for them; an offline build can use local material.

Before delivery, the skill renders the saved deck, checks layout and text fit, reads back the PowerPoint file, and asks for a claim self-check against the underlying source records. An independent reviewer then inspects the exact file and its rendered pages, and the deck is delivered only when that review accepts it and, after any revision, a fresh reader confirms it; when no review command-line tool is available, the workflow produces a review packet for the agent's own reviewer instead. The build reports and slide renders let you inspect what was produced before sharing it. Delivery provides the editable PowerPoint after the required checks pass, and a rejected build remains available for repair.

You may import the PPTX into Google Slides, but should inspect the imported version separately because fonts, wrapping, crops, charts, and object order may change. Automated checks support your review; you remain responsible for factual accuracy, source rights, and the final decision to use or publish a deck.
