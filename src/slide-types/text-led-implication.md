# Text-Led Implication

## Use when

Use this archetype when qualitative reasoning, definitions, mechanisms, or a short chain of evidence carries the argument and the audience needs a separately visible implication, consequence, uncertainty, or decision.

Use [`chart-led insight`](chart-led-insight.md) when a quantitative pattern can prove the conclusion by itself. Use [`argument with chart`](argument-with-chart.md) when the verbal argument remains primary but a chart is required as corroborating proof.

## Narrative contract

The main region explains what is true and why; the implication region states what changes for the audience without repeating the action title or summarizing the main text.

## Content contract

- one action title spanning the complete page or a theme-approved split-title variant;
- one structured reasoning block with a clear internal hierarchy;
- one implication block containing only decision-relevant consequences, qualifications, or actions;
- optional source, date, or evidence-status note when the reasoning depends on external material.

## Layout

Use an asymmetric reasoning-plus-implication split, normally `8 + 4` or `7 + 5` columns. The reasoning region should remain visibly primary; the implication region may be a full-height rail within the analytical canvas or a bounded panel according to the selected slide family.

Align the two regions to shared content-top and content-bottom guides. Start the implication region with the specific consequence, condition, or action. Omit a heading by default; when a specific branch heading is necessary to distinguish the region, align it and the first body baseline with a meaningful heading or paragraph start in the reasoning region rather than vertically centering unrelated text. Never use a generic “Implication” heading.

## Visual rules

- Apply the active variant from the theme's [`implication emphasis system`](../design/index.md#implication-emphasis-system); this archetype does not define a second container style.
- Apply the [`visible label gate`](../components/copy.md#visible-label-gate); the implication region must not rely on a generic micro-heading to announce its purpose.
- Use headings, short paragraphs, or genuine bullets to expose the reasoning structure; do not fill the main region with one uninterrupted wall of prose.
- Use selective emphasis only for decisive mechanisms or qualifications, following the [`copy` guide](../components/copy.md).
- Keep the implication region concise enough to scan independently and large enough to preserve the assigned typography roles without autofit.
- Preserve the deck's standard title, source, footer, and navigation zones even when the implication surface extends to a content edge.

## Failure modes

- implication copy that restates the action title or repeats the final paragraph;
- a colored side panel used only to make a text-heavy slide appear designed;
- equal visual weight for the reasoning and implication when one is clearly subordinate;
- several unrelated implications placed in one rail;
- dense prose compressed through smaller type or reduced margins;
- a one-off fill, line, or accent that is not part of the active theme.

## Acceptance test

Cover the implication region: the main text should still establish the claim and reasoning. Reveal the implication: it should change the audience's interpretation, decision, or next action rather than merely echo the page.
